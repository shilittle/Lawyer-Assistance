# Codex MCP examples

Use `config.stdio.toml` for the five-tool public legal server. `config.http.toml` targets an embedded application MCP endpoint at `http://127.0.0.1:8877/mcp`.

`config.privacy-workspace.stdio.toml` is an optional eight-tool configuration. Set its token-file placeholder to a client token created in the WebUI; do not put a bearer token in a config file or command argument.
