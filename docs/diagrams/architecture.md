# 法律与案件示意图系统总体架构

## 目标与边界

第一阶段把法律分析数据转换为可校验、可追溯、可离线查看的自包含 HTML 图示。权威中间表示是 `DiagramSpec 1.0`；模型可以生成或修订结构化数据，但不能生成模板代码、样式、脚本、坐标或未注册的关系。关系注册表冻结 42 种有方向、端点类型和中文语义的关系，其中 `related_to` 是唯一会触发 warning 的兜底关系。

本系统不是案件管理系统，也不代替律师判断。节点状态区分“主张”“有材料支持”“有争议”“已确认”和“未知”；`supported` 绝不自动升级为 `established`。示例只使用虚构数据。`diagram_authoring` 当前是显式 opt-in profile，但第一阶段尚未实现或强制校验 App 签发的逐次 CASE_RAW 批准凭据；因此本阶段只把虚构/公开数据视为已完成的生产边界，真实案件材料接入必须等可信、可审计的批准链落地。

## 组件

```text
MCP 客户端 / WorkBuddy
  │  snake_case 请求；MCP schema_version = 1
  ▼
legal-mcp: diagram_authoring profile
  │  profile、大小、字段和结果隐私门禁
  ▼
DiagramService
  ├─ DiagramSpec 结构与引用校验
  ├─ 关系注册表与模板语义校验
  ├─ 确定性模板布局
  ├─ 安全 SVG + 固定交互外壳
  └─ 内容寻址制品存储
       ▼
lawyer-assistance://diagrams/<artifact-key>
```

`crates/diagrams` 是独立领域边界。旧图数据若要使用，必须经过显式适配器转成 `DiagramSpec`；无法可靠映射的状态设为 `unknown`，缺少来源时产生诊断，不反向写回旧模型。

## 数据流

1. 客户端先读取模板清单和 Schema，选择与问题匹配的模板。
2. 客户端从批准的数据中提取节点、边、来源与状态，保留争议和缺口。
3. `validate` 在原始 JSON 边界先执行冻结 Draft 2020-12 Schema，再依次执行 typed 结构、跨引用、关系方向、模板语义和安全限制检查。
4. 无 error 后，`render` 规范化内容、计算 spec hash、执行固定布局并写入内容寻址 HTML。
5. 后续修改使用带 `expected_spec_hash` 的 patch；并发冲突返回错误，不覆盖较新版本。
6. `export` 只确认或重新物化已登记的 HTML，不启动浏览器、不访问远程资源。

## 信任分层

| 层 | 可以影响 | 不可以影响 |
|---|---|---|
| 模型/客户端 | 标题、节点、边、来源、有限布局提示和显示选项 | HTML、CSS、JS、CSP、任意 URL 请求、模板代码 |
| Schema/语义校验 | 接受或拒绝数据，给出诊断 | 推断案件真相、补造来源 |
| 模板/布局器 | 节点位置、边路由、图例与交互 | 改写事实状态或来源内容 |
| 制品服务 | 内容寻址、原子写入、URI 返回 | 暴露绝对路径、记录正文日志 |

## 确定性与审计

- 同一规范、模板版本和渲染版本必须得到相同字节与 URI。
- 每个制品记录 Schema、模板版本、spec hash 和 provenance。
- 节点、边和组通过 `source_refs` 回指来源；引用断裂是错误。
- 日志只记录工具、耗时、字节数、诊断计数和不可逆关联标识，不记录规范正文。
- 布局升级必须有快照差分和版本说明，不能静默改变既有制品语义。
- HTML 内嵌经过上下文转义的 provenance 记录；当 `show_sources=false` 时，来源记录、节点来源链接以及 provenance 的 `source_file_ids` 均不写入 HTML。
- 普通边在节点边界结束；同端点并行边采用确定性偏移，自环绘制到节点卡片之外，避免箭头被卡片遮挡。

## 交互与大图降噪

固定 HTML 运行时提供搜索、节点类型/状态筛选、争议点筛选、主体筛选、弱边隐藏、低重要性节点折叠、按 `collapsed_by_default` 的分组折叠、上下游聚焦、逐层展开、缩放/平移、适应视口、重置、详情/来源侧栏和打印。节点与边支持键盘聚焦和 Enter/Space 操作，状态同时使用文字、边框、线型、图标与图例表达；打印时强制浅色令牌。

500 节点、1200 边是契约硬上限，不是推荐规模。节点数大于 100 时渲染器强制隐藏弱边、折叠低重要性节点并显示性能提示；节点数超过 `layout_hints.max_initial_nodes` 时也默认折叠低重要性节点。降噪只改变初始可见性，不删除 DiagramSpec 数据。

## MCP 与制品消费边界

第一阶段只支持七个冻结模板、六个 MCP 工具和 HTML 格式。`diagram.list_templates` 返回每个模板的完整内置虚构示例，不暴露仓库路径；结构解析失败返回稳定 `invalid_request` 和经过白名单净化的 JSON Pointer，任意 metadata 键名不会进入模型可见诊断。`render` 和 `update` 返回不可变的 `lawyer-assistance://diagrams/<64-hex>` 引用；`export` 返回 HTML 描述符，不负责启动 GUI。桌面端或其他宿主需要提供该 URI 到本地制品的解析/展示通道，但不能因此取得扩大数据范围的权限。
