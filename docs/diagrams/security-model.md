# 图示系统安全模型

## 受保护对象

系统保护原始案件材料、个人与企业敏感信息、来源路径、访问凭据、法律分析状态、制品完整性以及宿主现有隐私承诺。攻击面包括恶意或误生成的 DiagramSpec、提示注入文本、超大图、危险 URL、来源路径泄露、并发覆盖和制品被当作主动网页执行。

## 数据准入

`diagram_authoring` 是显式 opt-in 能力，但第一阶段尚未实现或强制校验 App 签发的逐次 CASE_RAW 批准凭据。因此已完成的安全边界只覆盖虚构/公开数据；真实案件接入必须在批准凭据正向链落地后另行开放。CASE_RAW 范围不能由模型声明、文件名或“已脱敏”标签自行扩大。外部模型计费测试只能使用纯虚构 fixtures；API 密钥由凭据存储提供并禁止进入日志、样例、制品和版本控制。本次验收未调用 DeepSeek 或其他计费 API。

## 模型—渲染隔离

模型只影响 DiagramSpec 数据。模板 ID、节点类型、关系、状态、字段长度、集合数量、metadata 深度和布局提示均为封闭集合。渲染器自行生成 HTML、SVG、CSS、JS 和坐标，所有用户文本按所属 HTML 文本、属性或 JSON 上下文转义。

固定 HTML 外壳必须满足：

- CSP 默认 `default-src 'none'`，脚本和样式只允许渲染器写入的固定 nonce；输入数据无法控制 nonce、标签或 CSP。
- 不使用 `innerHTML` 注入用户文本，不使用 `eval`、`Function`、动态 import。
- 不提供表单、fetch/XHR、WebSocket、自动导航、远程字体或远程图片。
- URI 仅允许明确白名单协议且只展示；控制字符和危险协议拒绝。
- 用户字段不能进入 style、事件处理器、SVG path 或 CSS selector。

## 资源与拒绝服务

Schema 限制 500 节点、1200 边、100 组、1000 来源及各字段长度；MCP adapter 限制 4 MiB 工具 envelope，服务在写盘前限制 4 MiB 规范化 Spec 和 12 MiB HTML。超过 100 节点时强制隐藏弱边、折叠低重要性节点并显示性能提示；超过 `max_initial_nodes` 时也折叠低重要性节点，但不删除数据。当前 stdio 传输在 serde 分配前仍没有图示专用的字节/JSON 深度预扫描，这是剩余拒绝服务风险；HTTP 传输另有 body 限制，不能把它误写成 stdio 防护。

## 来源与路径

来源记录面向审计，不能成为文件系统访问能力。`file_name` 只接受 basename；locator、attachment、URI 及其他受检文本中的本地绝对路径会被拒绝，`artifact_id` 和 provenance 的 `source_file_ids` 都必须是受控标识且不直接拼接路径。URI 只允许白名单协议、只展示、不自动请求。`show_sources=false` 时来源记录、来源链接和 provenance 的 `source_file_ids` 不进入 HTML。`source_refs` 必须闭合，删除被引用来源必须失败。

## 制品完整性

制品使用规范化 Spec（其中包含模板版本）计算内容地址，HTML 内嵌渲染器版本；同一地址出现不同内容时拒绝覆盖。文件写入位于专用 output root 下并采用原子安装。路径必须在写入前解析并验证仍位于根目录。更新要求 `expected_spec_hash`，防止静默覆盖并发版本。provenance 记录生成者、时间、版本、来源 ID、确认状态及模型/确定性代码的职责范围。

## 日志与错误

日志只保留工具名、版本、耗时、输入/输出字节数、诊断计数和不可逆请求标识。不得记录标题、节点、边、来源、URI 查询、用户正文或凭据。反序列化错误返回稳定 `invalid_request` 和经过闭集白名单净化的 JSON Pointer；到达任意 metadata 键时路径截断在 `/metadata`，不得回显攻击者控制的键名或正文。语义诊断经模型可见结果隐私扫描后返回。

## 安全测试门禁

发布前至少覆盖脚本标签、事件属性、引号闭合、SVG/MathML、双重编码、危险 URL、控制字符、双向文本字符、超长 Unicode、深层 metadata、重复/悬空 ID、路径穿越、符号链接逃逸、并发 hash 冲突、内容寻址稳定性和离线网络断言。

## 已知剩余风险

单文件 HTML 依赖固定内联运行时、严格 CSP、上下文转义和禁止动态代码；固定、版本化 nonce 只适用于不接收用户模板代码的自包含制品，不是输入净化的替代品。宿主可能在工具调用前已获得超出范围的材料，提示词无法修复该问题；正式真实案件链路仍缺 App 到 MCP 的可验证批准凭据。`lawyer-assistance://diagrams/...` 需要宿主实现本地解析/展示，MCP `export` 目前只返回描述符。大图即便通过硬上限也可能暴露过多上下文，因此调用者仍应最小化数据范围并按争点拆图；第一阶段也只承诺 HTML，不提供 SVG/PNG 对外导出。
