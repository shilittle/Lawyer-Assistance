# AI 增量升级说明

本轮在 V1.0.0 Web 工作区上保留既有案例检索增量，继续使用 Windows 本地后台服务与浏览器界面。交付文件见 [v1.2.0 发布页](https://github.com/shilittle/Lawyer-Assistance/releases/tag/v1.2.0)。便携包包含本地运行依赖，日常使用不需要 Python、Node 或单独安装 OCR 软件。

## 升级与首次设置

1. 停止旧版本服务，解压新便携包，使用原来的 `%LOCALAPPDATA%\LawyerAssistanceWeb` 工作区启动。
2. 首次打开旧 Web 工作区时，后台先通过 SQLite Backup API 写入 `workspace.pre-ai-v1.sqlite`，核对完整性与源数据指纹，再事务升级到 `web-workspace-v2`。已有备份若损坏或与当前数据不一致，会保留原备份并另建带唯一标识的备份。分组、原件、字典、收藏、结果和会话保留。备份仍为当前 Windows 用户的加密数据；旧 Tauri 工作区不在此次迁移范围。
3. 在“设置”选择供应商预设，输入 API Key，点击获取模型列表，勾选启用模型并保存。分别选择对话、脱敏、写作、OCR 模型；可以共用同一模型。旧单模型配置会变为一个已启用模型。
4. 国内官方预设默认允许发送用户选中的原文。自定义地址需要确认归属和原文发送设置；修改地址后重新判断。未信任的供应商只能接收有效脱敏材料引用，不能直接读取原件或上传附件。

智谱 GLM、DeepSeek、通义千问、硅基流动、火山方舟、Kimi 和自定义兼容接口提供预设。模型列表以当前密钥的实际接口响应为准；鉴权失败、限流和不支持的接口会显示失败，不能用预设名单冒充联网发现成功。API Key 保存在 Windows 凭据管理器。

## 材料脱敏

配置脱敏模型后，材料采用“提取或视觉 OCR → 本地预扫描 → LLM 定位 → 本地核验和替换 → LLM 查漏 → 本地残留检查”的处理流程。支持 TXT、DOCX、PDF、PNG、JPEG、WebP；PDF 每页转图，DOCX 内嵌图片也进入 OCR。没有配置模型时，保留旧版本的本地 TXT/DOCX 流程并如实标识处理方式。

大模型返回原文片段和出现位置，本地核验后生成稳定别名，不接受模型直接重写材料作为脱敏成品。非脱敏目标的金额、日期和事实正文由本地替换过程保持。歧义、缺页、非法响应和未完成请求不会自动发布结果。长材料按块处理，完成的 OCR 和实体定位阶段保留检查点；重启后的未知云请求由用户点击继续。

新脱敏成品统一为 UTF-8 纯 TXT。单份导出和批量 ZIP 均使用保存的脱敏正文；原始材料格式和排版不作为脱敏输出格式。复核、字典变更、结果撤销和过期检查继续生效。

## 法律与 AI 搜索

法律搜索默认按法律归组，另有逐条视图。完整匹配集计算法律总数、命中条文数、筛选、排序与分页；派生二元索引只加速召回，未命中可靠索引时使用完整 SQL 后备。法名、别名、编章主题、效力层级和状态共同参与相关性排序。可以按类型、效力、地域、状态、案件日期筛选，按相关性、效力、公布或施行日期排序。

历史版本和关联法规默认显示；点击历史版本可分页读取该版本的实际条文。案件日期仅用于检索版本范围，不替代案件事实和溯及力判断。

AI 搜索支持案情描述、附件以及已有材料选择。模型可调整关键词、多次搜索并读取本地条文、版本和最高法案例；每段执行最多 8 轮、24 次工具调用，达到上限后保留步骤并可继续。引用标识和逐字引文由数据库核验。案例库只覆盖来源清单声明的最高人民法院官方案例，缺失或校验失败时显示不可用。

本次已导入用户提供的 `最高法案例_TXT资料包_20260909.zip`。834 个来源 TXT 条目核验哈希后合并为 759 条主案例或合集：279 条指导案例、61 条参考案例、419 条典型案例合集。典型合集可能包含多个案件，不能把 419 解释为单案数量。保留不同来源版本、撤销标识和来源入口；指导案例 45 使用资料包中的洛阳中院官方转载。可在“法律检索 → 案例”按类别筛选并读取完整正文，AI 搜索、写作和会话也使用同一案例库。

## 文书写作与会话

“文书写作”按案件描述、文书类型和写作要求组织内容，可调用同一法律工具。任务创建时即保存，完成后保存正文和引用；手动修改生成新版本，重新生成也保留历史。预览和 TXT、DOCX、PDF 导出使用共同的 Markdown 解析结构：TXT 为纯文本，DOCX 为真实标题、段落、列表和表格，PDF 默认使用中文 A4 排版。导出不再次调用模型。

会话首次完整回答后自动命名，手动改名后不再自动覆盖。选择材料和附件后显示本轮引用；切换供应商或继续旧会话时重新检查材料有效性和发送策略。后台接受的 AI 任务与浏览器生命周期分离，页面关闭不取消任务，用户可以显式取消。

## 存储和权限

原件、映射、私密历史、检查点继续由本地后台以 Windows DPAPI 加密。材料内的伪造指令仅作为文档内容，不获得工具、配置、文件写入或网络权限。AI 可使用的工具仅为本地只读法律和官方案例检索；现有公共 MCP 七工具及私密工作区十工具契约保持兼容。

便携包包含 Pdfium、Typst、思源宋体和各自许可，以及法律库、案例库、派生索引和来源清单。包内不含 API Key、用户工作区或模拟材料。

## 启动时没有反应

升级前请在旧版本文件夹中双击 `Stop-Lawyer-Assistance.vbs`，等待旧服务停止，再启动新版本。关闭网页不会停止后台服务；不同目录的版本共用同一个用户工作区，不能同时启动。新版本遇到其他目录的实例、端口占用或启动失败会显示中文错误提示。请完整解压 ZIP 后启动，勿直接在压缩包内运行脚本。
